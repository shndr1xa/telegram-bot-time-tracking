# Telegram-бот для учета трудозатрат

Проект разработан в рамках выпускной квалификационной работы.

## Назначение системы

Бот предназначен для упрощения процесса ввода трудозатрат сотрудниками и последующей загрузки данных в систему 1С:ITILIUM.

Решение позволяет сократить время на внесение данных и исключить двойной ввод информации.

## Основной функционал

- ввод трудозатрат через Telegram
- выбор последних задач
- контроль дневной нормы (8 часов)
- редактирование и удаление записей
- формирование JSON-файла для загрузки в 1С

## Архитектура решения

Система состоит из двух компонентов:
1. Telegram-бот (Python, aiogram)
2. Внешний обработчик 1С:ITILIUM

Обмен данными осуществляется через JSON-файл (entries.json).
