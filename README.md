# 🤖 Трекер Трудозатрат

> **Удобный Telegram-бот** для ежедневного ввода, контроля и отчётности по трудозатратам.  
> Помогает сотрудникам соблюдать 8-часовую норму, отправляет умные напоминания и делает процесс максимально быстрым и приятным.

## Ключевые возможности

| Функция                    | Описание                                                                 |
|---------------------------|--------------------------------------------------------------------------|
| **Авторизация**        | По ФИО + персональному ключу (двухфакторная защита)                     |
| **Гибкий ввод**        | Записи за сегодня или вчера, выбор даты кнопками                         |
| **Быстрый повтор**     | «Повторить последнюю» или выбор из 3 последних задач                     |
| **Редактирование**     | Изменить/удалить последнюю запись в один клик                            |
| **Статус в реальном времени** | Сколько внесено, сколько осталось до нормы                              |
| **Умные напоминания**  | Каждый день в 18:00, если норма не выполнена                             |
| **Завершение дня**     | Проверка, что внесено ровно 8 часов (или предупреждение)                 |
| **Docker**             | Один образ, готов к продакшену                                           |
| **Локальное хранилище**| JSON-файлы (без внешних баз данных)                                      |

## Запуск (Docker — рекомендуется)

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/ВАШ_АККАУНТ/work-hours-bot.git
cd work-hours-bot

# 2. Создайте .env файл
echo "BOT_TOKEN=123456:ABC-DEF1234ghIkl-zyx57W2v1u123ew11" > .env

# 3. Подготовьте список сотрудников
mkdir -p data
cat > data/employees.json << 'EOF'
[
  {
    "full_name": "Иванов Иван Иванович",
    "key": "EMP001"
  },
  {
    "full_name": "Петрова Анна Сергеевна",
    "key": "EMP002"
  }
]
EOF

# 4. Соберите образ и запустите
docker build -t work-hours-bot .
docker run -d \
  --name hours-bot \
  --restart unless-stopped \
  -v $(pwd)/data:/app/data \
  --env-file .env \
  work-hours-bot
```

> **Важно**: Обязательно монтируйте том `-v $(pwd)/data:/app/data`, иначе все данные будут теряться при перезапуске контейнера.

## Конфигурация

### `data/employees.json`

```json
[
  {
    "full_name": "Иванов Иван Иванович",
    "key": "EMP001"
  },
  {
    "full_name": "Сидоров Пётр Петрович",
    "key": "EMP042"
  }
]
```

- `full_name` — Полное имя сотрудника (используется при авторизации)
- `key` — Уникальный код

### Переменные окружения

| Переменная   | Назначение                    |
|--------------|-------------------------------|
| `BOT_TOKEN`  | Токен вашего Telegram-бота    |

## Как пользоваться ботом

1. Найдите бота в Telegram и нажмите **/start**
2. Введите **ФИО** полностью (как в `employees.json`)
3. Введите **персональный ключ**
4. Готово! Откроется главное меню:

**Главное меню:**
- **Сегодня** — ввести запись за сегодня
- **Вчера** — ввести запись за вчера
- **Статус** — текущий прогресс за день
- **Мои записи** — список всех записей за сегодня
- **Повторить последнюю** — мгновенное копирование предыдущей задачи
- **Изменить последнюю** / **Удалить последнюю**
- **Проверить часы** — остаток до 8 часов
- **Завершить день** — финальная проверка нормы

**Процесс ввода записи:**
```
Дата → Способ ввода (Новая / Последние задачи) 
→ WorkItemID / номер задачи 
→ Вид работы (Разработка, Тестирование, Аналитика, Документация, Совещание, Поддержка или своё)
→ Количество часов (1–8)
→ Комментарий 
→ Подтверждение и сохранение
```

---

## Напоминания

Каждые 5 минут бот проверяет время.  
В **18:00** всем верифицированным сотрудникам, у кого меньше 8 часов, приходит сообщение с остатком и быстрыми кнопками.

---

## Безопасность

- Доступ только для сотрудников из `employees.json`
- Каждый пользователь проходит двухэтапную верификацию
- Данные одного пользователя недоступны другим
- Ключи хранятся только в `meta.json` (не передаются в открытом виде)
